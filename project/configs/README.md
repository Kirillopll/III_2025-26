# configs

В этой папке лежат настройки проекта. Они вынесены отдельно, чтобы обучение,
сервис и тесты использовали одни и те же пути, признаки и параметры.

## Файлы

- `config.yaml` - основной конфигурационный файл проекта.
- `.env.example` - пример локальных переменных окружения.

## Что задается в `config.yaml`

- название проекта и версия;
- путь к исходному датасету `data/raw/application_train.csv`;
- список числовых и категориальных признаков;
- целевая переменная `TARGET`;
- параметры разбиения данных на train/validation/test;
- список моделей для экспериментов;
- пути для сохранения модели, метрик, предсказаний и графиков;
- настройки FastAPI-сервиса.

## Что можно менять

Если нужно провести новый эксперимент, обычно достаточно изменить:

- `data.max_rows` - сколько строк брать из датасета для быстрого запуска;
- `features.numeric` и `features.categorical` - набор признаков;
- параметры моделей в блоке `models`;
- `artifacts.dir` - папку для сохранения результатов.

После изменения конфига нужно заново запустить обучение:

```powershell
.\.venv\Scripts\python.exe -m src.train
```

## Важное замечание

Реальный `.env` с локальными настройками или секретами не нужно коммитить.
В репозитории должен лежать только пример `.env.example`.
