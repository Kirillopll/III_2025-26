# Артефакты проекта

Эта папка нужна для файлов, которые создаются во время запуска проекта.
Большинство таких файлов не коммитятся в Git, потому что они могут быть большими или пересоздаются автоматически.

## Что здесь появляется

После проверки данных:

```text
data_profile.json
```

Файл создаётся командой:

```bash
python scripts/inspect_data.py
```

В нём хранится краткий профиль датасета: число колонок, доля дефолтов, количество числовых/категориальных признаков и признаки с большим числом пропусков.

После обучения модели:

```text
credit_risk_model.joblib
credit_risk_model.metrics.json
```

Файлы создаются командой:

```bash
python -m credit_risk_service.ml.train
```

- `credit_risk_model.joblib` - сохранённый пайплайн обработки признаков и лучшая модель.
- `credit_risk_model.metrics.json` - метрики всех обученных моделей.

После запуска API могут появиться:

```text
uvicorn.out.log
uvicorn.err.log
```

Это логи локального запуска сервиса.

## Почему этих файлов нет в коммите

В `.gitignore` указано:

```text
artifacts/*.joblib
artifacts/*.pkl
artifacts/*.json
```

Поэтому модель и JSON-отчёты остаются локально и не отправляются на GitHub.
Это нормальная практика: в репозитории хранится код и инструкция, а данные, модель и отчёты создаются командами из `README.md`.

## Что нужно показать на защите

Для демонстрации можно заново выполнить:

```bash
python scripts/inspect_data.py
python -m credit_risk_service.ml.train
```

После этого открыть:

```text
artifacts/credit_risk_model.metrics.json
artifacts/data_profile.json
```

и показать, что модель обучилась, а метрики сохранились.
