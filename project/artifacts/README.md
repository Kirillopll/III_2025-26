# Артефакты проекта

Папка содержит результаты обучения и проверки модели.

После команды:

```bash
python -m src.train
```

создаются:

- `model.joblib` - обученный пайплайн обработки признаков и финальная модель;
- `model_metadata.json` - дата обучения, список признаков, финальная модель и метрики;
- `metrics.csv` - таблица сравнения моделей;
- `metrics.json` - те же метрики в JSON;
- `test_predictions.csv` - вероятности дефолта на тестовой части;
- `feature_importance.csv` - важность признаков;
- `error_by_hour.csv` - средняя ошибка вероятности по часу подачи заявки;
- `default_by_hour.png` - средняя доля дефолтов по часу заявки;
- `prediction_vs_actual.png` - фактический класс и предсказанная вероятность;
- `feature_importance.png` - топ важных признаков;
- `error_by_hour.png` - ошибка по часу заявки.
