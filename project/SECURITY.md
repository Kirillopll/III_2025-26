# Безопасность

В проекте используются только открытые данные Kaggle Home Credit Default Risk.

Правила:

- не коммитить реальные секреты, токены и пароли;
- не хранить `kaggle.json` внутри проекта;
- не добавлять большие исходные CSV-файлы в Git;
- использовать `.env.example` как шаблон переменных окружения;
- хранить локальные настройки в `.env`, который игнорируется Git.

Входные данные API проходят валидацию через Pydantic-схемы FastAPI.
